The short version

One person, and a crew that does not get tired

WHOMP is made by one person directing a crew of AI agents. The crew does the typing.

Work goes out in lanes. 982 of them have landed since the first commit, on 2026-07-11.

The lane

One job, and a written list of what it may touch

A lane is one job, done in a fresh copy of the game by an agent that has never seen this project and will never see it again.

A lane writes down which files it is allowed to touch before it touches any of them.

Two lanes are never handed the same file, because the day they were, the tree stopped building and nothing looked wrong until somebody took an upgrade.

The gate

Finished is not a word the lane gets to use

A lane says it is done. That is where the argument starts.

A run of tests that reported nothing is a failed run. Zero is not a pass.

A new check has to be made to fail on purpose before anybody believes it works.

Anything touching accounts, saves, other players or the deploy is read by somebody who did not write it.

The stop

The most useful lane of that week wrote no code

A lane is handed a premise along with its job, and the premise is sometimes wrong.

A lane that proves its own job was based on something untrue, and stops, has finished. Three did that in one day, and all three were right.

The deploy

Two tracks, and the careful one is second

There are two places to play this, and both of them are a link.

Every build that goes green goes to the preview track. The weekly one is only ever a preview build that already proved itself.

Nothing ships because it is ready. It ships because a person named that exact build and said to ship it.

Why it holds

A rule that cannot fail is not a rule

A rule nobody can check is a note. Every rule on this page is a check that can fail, and most of them were written the day after they were needed.

No em dashes in anything a player can read. A machine checks that one, which is the whole point.

The dev log on this site is not written for it. It is built out of the same releases and the same changes the work actually produced, so it says what happened rather than what somebody remembered.

Read what landed, day by day. Or look up what is waiting for you in the wiki. Or skip all of it and play the thing.
