Relics

Relics are stackable run pickups. Their cards carry the game description, rarity, stack ceiling, source stat payload and whether the arena draft includes them.

Every value on this page is read from a verified generated artifact at build time, against game@d2b39395. The generator refuses stale artifacts, missing domains, missing entries and dead relations before it writes a page. Source: src/data/relics.ts#RELICS. Optional director notes have 0 of 36 coverage, so these cards use canonical mechanics and authored registry copy only.

There is no relic tier letter here. The measurement artifact explicitly does not cover relics because a relic needs a reference build and chest-economy model before its delta means anything. The roster is complete; the ranking is honestly unmeasured.
